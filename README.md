# Personal website

## Edit your content

- `content/pages/home.md` — homepage text
- `content/pages/about.md` — About page text
- `content/projects/` — projects; each Markdown file becomes a project page
- `content/posts/` — blog posts; each Markdown file becomes a post page
- `public/cv/cv.pdf` — CV shown at `/cv/`
- `src/site.config.ts` — site title, author, description, domain, and navigation

## Start the site

```sh
npm install
npm run dev
```

## Build for production

```sh
npm run build
```
